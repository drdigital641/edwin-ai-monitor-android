Hyper Power questions

What is a sodium-ion car battery?

A 12V battery that uses sodium-ion cells in place of lead plates and acid. It fits the same tray sizes as the battery it replaces.

Which size fits my car?

Match the size code on your current battery (for example B24, D26 or L3). The workshop will confirm the terminal layout.

How much is a Hyper Power battery?

Prices depend on size. WhatsApp KohDen or ask an authorised workshop for a quote.
