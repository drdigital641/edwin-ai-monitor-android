Wiper size guide

Find your size, then check which MOON blade comes in it.

Call Kohden 6966 6565

Three ways to find it

  1. Read the old box or bladeThe length is printed, usually in inches.
  2. Measure tip to tipMeasure the rubber end to end, driver and passenger side separately, plus the rear.
  3. Call KohdenGive the make, model and year; they match the size and type.
