J2534, DoIP and CAN FD explained

By CSKA Auto Enterprise · Updated 19 October 2026

J2534 is a standard that lets a workshop use the carmaker's own software through an aftermarket interface to reprogram modules. DoIP is diagnostics over Ethernet, used by many newer cars for fast data transfer. CAN FD is a faster version of the CAN bus. A scanner needs the right one to talk to, code or program a newer car.

J2534 pass-thru

A J2534 device sits between a laptop or tablet and the car, so the carmaker's service software can flash new module software. Autel's MaxiSYS MS909 and MS909 S2 come with a J2534 VCI, and the THINKTOOL Master X2 and Expert 391 support J2534.

DoIP

Diagnostics over Internet Protocol uses an Ethernet connection through the OBD port. It moves large amounts of data quickly, which newer cars need for programming. Tools such as the THINKTOOL Lite 2, SE and Expert 391 and the Autel MS908S3 support it.

CAN FD

CAN with Flexible Data-rate carries more data per message than classic CAN. If a scanner does not support it, it may not connect to some modules on newer cars at all.

Before you program a module

  • Stable voltage connect a programming power supply such as the THINKPPS 150.
  • Stable internet online programming downloads files during the job.
  • Right software confirm the tool supports that make, model and module before you start.

Questions

Do I need J2534 if my scanner already programs?

Not always. Many scanners program supported modules on their own. J2534 adds the option to use the carmaker's own software where the scanner does not cover a job.

Why did my scanner not connect to a new car?

The car may use DoIP or CAN FD on that module. Check that your tool and its VCI support both, and that the software is up to date.
