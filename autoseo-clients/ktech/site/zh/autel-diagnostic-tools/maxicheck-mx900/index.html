Autel MaxiCheck MX900

8 英寸平板服务工具，含 40 多项维护功能。

MaxiCheck MX900 是 8 英寸平板服务工具，用于全系统诊断与车间维护功能，具备 AutoVIN、DoIP 与 CAN FD，以及 Pre 与 Post Scan。

主要功能

  • 广泛覆盖美国、亚洲与欧洲车型，并对所有电子系统提供原厂级系统覆盖。
  • 故障码、实时数据、ECU 信息、主动测试与特殊功能。智能 AutoVIN，方便识别车辆。
  • DoIP 与 CAN FD 协议。支持 Pre & Post Scan。支持全部 OBD-II 协议与 10 种测试模式。
  • 40 多项维护服务功能，包括柴油颗粒滤清器强制再生、转向角传感器（SAS）复位、机油保养与电池登记 / BMS、保养里程与周期复位，以及开合电子驻车钳（EPB）以便更换刹车片。
  • Data Manager 用于车辆历史、车间信息、客户记录、图片、报告与数据记录。

适合车厂

适合需要一台 8 英寸日常服务平板的车厂，用于全系统诊断和常见复位——DPF、SAS、机油与电池 / BMS、保养周期以及电子驻车——并带 Pre 与 Post Scan。
