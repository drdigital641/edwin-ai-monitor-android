EV Upgrade Kit

Autel MaxiSYS 电动车诊断升级套件

为兼容的 MaxiSYS 平板增加电动车电池包诊断。

此升级套件可为兼容的 MaxiSYS 平板增加电动车诊断。内含 EVDiag Box 及特定车型转接头，用于电动车电池包诊断。

主要功能

  • 兼容 MaxiSYS Ultra、MaxiSYS Ultra ADAS、MaxiSYS MS919 与 MaxiSYS MS909。
  • 针对美国、欧洲与亚洲的电动、汽油、柴油及混合动力车辆的进阶诊断。
  • 针对主流电动车的深入电池包诊断，手册点名 BMW、Tesla 与 Volkswagen/Audi。
  • 荷电状态（SoC）与健康状态（SoH）分析，了解电池实际状况。
  • 通过专用转接头与跳线进行分析，并提供详细接线图以便更安全地测试。
  • 手册也列出对 Caterpillar、Cummins 与 Hino 发动机的支持。

适合车厂

适合已有 MaxiSYS Ultra、Ultra ADAS、MS919 或 MS909，希望增加电动车电池包诊断（包括荷电状态与健康状态分析）的车厂。

硬件与协议

套件内容
EVDiag Box 以及车型专用转接头与跳线，装在硬箱中（如手册所示）
兼容平板
MaxiSYS Ultra、MaxiSYS Ultra ADAS、MaxiSYS MS919、MaxiSYS MS909

覆盖范围. 美国、欧洲与亚洲的电动、汽油、柴油及混合动力车辆。电池包诊断点名：BMW、Tesla、Volkswagen/Audi。手册列出的发动机支持：Caterpillar、Cummins、Hino。
