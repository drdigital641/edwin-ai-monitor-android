Relearn TPMS selepas tukar tayar: kenapa lampu masih menyala

Relearn TPMS memberitahu kereta sensor tekanan tayar mana berada di roda mana. Apabila pelanggan kembali dengan lampu TPMS menyala selepas tayar baru, pusingan tayar atau sensor baru, biasanya kereta belum mengenal ID sensor itu. Ini perkara yang perlu disemak, ikut turutan.

Jawapan ringkas

Lampu TPMS selalunya kekal menyala selepas kerja tayar kerana kereta tidak mengenal sensor atau kedudukannya. Pastikan setiap sensor menjawab alat TPMS, ganti atau program sensor yang rosak, kemudian buat relearn mengikut cara pengeluar kereta: relearn automatik semasa memandu, relearn statik, atau relearn OBD dengan alat.

01Kenapa lampu menyala selepas kerja tayar

Setiap sensor TPMS langsung berada di dalam roda dan menghantar ID serta tekanannya sendiri kepada kereta. Jika sensor rosak semasa tayar ditukar, baterinya habis, atau sensor baru mempunyai ID yang belum pernah dikenal, sistem tidak dapat memadankannya dan lampu amaran kekal menyala.

Pada sesetengah kereta, memusingkan roda pun sudah perlu relearn, kerana kereta menunjukkan tekanan bagi setiap kedudukan roda.

02Semakan sebelum relearn

  1. C1
    Tetapkan tekananIsi angin setiap tayar mengikut tekanan pada label pintu dahulu. Tayar yang kurang angin akan mengekalkan lampu walaupun sensor elok.
  2. C2
    Aktifkan setiap sensorGuna alat TPMS pada setiap injap untuk membaca ID sensor, tekanan dan keadaan bateri. Sensor yang tidak menjawab ialah suspek pertama.
  3. C3
    Ganti atau programPasang sensor baru, atau program sensor kosong yang boleh diprogram supaya sepadan dengan kereta, sebelum mula relearn.

03Tiga cara relearn

Pengeluar kereta menggunakan prosedur berbeza, dan cara yang betul bergantung pada jenama, model dan tahun. Alat TPMS menunjukkan prosedur untuk kereta yang sedang dibaiki.

  • Automatik: kereta mengenal sensor semasa dipandu untuk seketika
  • Statik: kereta dimasukkan ke mod belajar, kemudian setiap sensor diaktifkan mengikut turutan
  • OBD: alat membaca ID sensor dan menulisnya ke kereta melalui port OBD

Jika lampu masih menyala selepas relearn yang betul, imbas modul TPMS untuk kod kerosakan: masalahnya mungkin pada penerima atau modul, bukan sensor.

Soalan

Perlukah relearn setiap kali tukar tayar?

Tidak semestinya. Ia bergantung pada kereta dan sama ada sensor diganti atau roda bertukar kedudukan. Prosedur untuk jenama, model dan tahun itu menunjukkan bila relearn diperlukan.

Bolehkah sensor lama digunakan semula pada tayar baru?

Selalunya boleh, jika ia masih menjawab alat TPMS, baterinya elok dan ia tidak rosak semasa tayar dibuka. Semak dahulu sebelum memasang tayar baru.
