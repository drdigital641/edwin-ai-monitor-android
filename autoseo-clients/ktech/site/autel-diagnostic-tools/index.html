Ultra S2

Autel MaxiSYS Ultra S2

MaxiSYS S2 series flagship tablet with 6-in-1 VCMI2.

The Ultra S2 builds on the Autel MaxiSYS Ultra with upgraded hardware and advanced diagnostic features, for near OEM-level diagnostics and beyond.

Key features

  • 6-in-1 VCMI2: VCI / J2534 pass-thru programmer, 4-channel oscilloscope, multimeter, waveform generator, CAN-Bus tester, and standalone Remote Expert device, in a lighter, more compact chassis.
  • MAX hands-free virtual assistant: say “Hey MAX, open service menu” to start a system scan, open maintenance tasks, or run active tests.
  • Topology 3.0 dynamic network analysis, with colour-coded module status and the ability to ping ECUs to test signal quality and network integrity.
  • Data-driven PID analysis: data visualisation, live data fusion across systems, parameter grouping, and reference sampling for pre- and post-repair comparison.
  • Split-screen diagnostics, including Live Data + Oscilloscope, Topology + component location, and Fault Scan + Ping Network.

For workshops

For workshops that want one flagship tablet for near OEM-level diagnostics plus measurement: a 4-channel oscilloscope, multimeter, waveform generator and CAN-Bus tester, with hands-free MAX control and topology mapping.

MS919 S2

Autel MaxiSYS MS919 S2

11-inch S2 tablet with the same 6-in-1 VCMI2 measurement set.

The MS919 S2 is the 11-inch model in the MaxiSYS S2 series. It shares the VCMI2 vehicle communication and measurement device with the Ultra S2, including the 4-channel oscilloscope and multimeter. A charging dock is not included.

Key features

  • VCMI2 with VCI / J2534 pass-thru, 4-channel oscilloscope, multimeter, waveform generator, CAN-Bus tester, and Remote Expert.
  • Live Data + Oscilloscope split-screen (Ultra S2 and MS919 S2 only, per the brochure).
  • MAX voice assistant, Topology 3.0, and enhanced PID analysis (visualisation, live data fusion, parameter grouping, reference sampling).
  • DoIP, CAN FD, J2534 and D-PDU protocols. Multi-system graphic live data. Auto scan and topology with module location.

For workshops

For workshops that want the S2 software and a built-in 4-channel oscilloscope on an 11-inch tablet, without the Ultra S2’s 13.7-inch screen or charging dock.

MS909 S2

Autel MaxiSYS MS909 S2

11-inch S2 tablet with VCI 2 and the MAX voice assistant.

The MS909 S2 is the 11-inch S2 tablet that ships with VCI 2 rather than VCMI 2. It has MAX voice assistance, topology with module location, and the same DoIP, CAN FD, J2534 and D-PDU protocols. A 4-channel oscilloscope and multimeter are not included.

Key features

  • MAX hands-free virtual assistant for system scans, maintenance tasks and active tests.
  • Topology based on the ECU network and module location, auto scan, and multi-system graphic live data.
  • Enhanced PID analysis: data visualisation, live data fusion, parameter grouping and reference sampling.
  • VCI 2 vehicle communication interface. Oscilloscope and multimeter are not included on this model, and a charging dock is not included.

For workshops

For workshops that want the new S2 tablet, MAX voice control and topology mapping, and do not need a built-in oscilloscope or multimeter.

MS909EV

Autel MaxiSYS MS909EV

Intelligent EV diagnostics and high-voltage system testing.

The MS909EV is for secure high-voltage system testing and analysis. It covers all functions of the MS909, plus EV high-voltage system diagnostics and battery-pack diagnostics, and ships with a MaxiFlash VCI and EVDiag Box (as shown in the brochure).

Key features

  • Advanced diagnostics for U.S., European and Asian electric, gas and diesel, and hybrid vehicles.
  • Rapid analysis of EV high-voltage systems, including the ability to read and erase codes and view live data.
  • In-depth battery-pack diagnostics for popular EVs including BMW, Tesla and Volkswagen/Audi, with State of Charge and State of Health analysis.
  • Battery analysis via the BMS (battery management system), specialty cable and jumpers, with detailed connection diagrams for safer testing.
  • Topology module mapping for 50+ brands including Mercedes-Benz and BMW: automatically scan the communication status of all ECU modules.

For workshops

For workshops that service electric and hybrid vehicles and need high-voltage testing plus battery-pack State of Charge and State of Health analysis, including BMW, Tesla and Volkswagen/Audi named in the brochure.

EV Upgrade Kit

Autel MaxiSYS EV Diagnostics Upgrade Kit

Add EV battery-pack diagnostics to a compatible MaxiSYS tablet.

This upgrade kit adds EV diagnostics to a compatible MaxiSYS tablet. It includes the EVDiag Box and adapters for specific vehicles, so you can run battery-pack diagnostics on electric vehicles.

Key features

  • Compatible with the MaxiSYS Ultra, MaxiSYS Ultra ADAS, MaxiSYS MS919 and MaxiSYS MS909.
  • Advanced diagnostics for U.S., European and Asian electric, gas and diesel, and hybrid vehicles.
  • In-depth battery-pack diagnostics for popular EVs including BMW, Tesla and Volkswagen/Audi.
  • State of Charge and State of Health analysis for true battery condition.
  • Battery analysis via specialty adapters and jumpers, with detailed connection diagrams for safer testing.

For workshops

For workshops that already have a MaxiSYS Ultra, Ultra ADAS, MS919 or MS909 and want to add EV battery-pack diagnostics, including State of Charge and State of Health analysis.

Autel MaxiSYS MS908S3 Kit

Advanced diagnostics and information system, with XP400 Pro key programmer included.

The MS908S3 Kit is an advanced diagnostics and information system. The brochure lists a new included XP400 Pro key programmer, together with a MaxiFlash LVCI (SAE J2534, RP1210).

MS906Pro

Autel MaxiSYS MS906Pro and MS906Pro-TS

8-inch MaxiSYS Pro tablets, with a TPMS variant.

The MS906Pro and MS906Pro-TS are 8-inch MaxiSYS Pro tablets. Both include a VCI V200. The MS906Pro-TS adds complete TPMS functionality and 1-Sensor programming. Some software features in the brochure are marked as requiring an additional purchase.

Key features

  • All-system AutoSCAN with ADAS identification, PreSCAN and PostSCAN diagnostic reports, repair data, advanced ECU coding and adaptations, and bi-directional controls with 26 service functions.
  • Scan VIN by text or barcode with the camera, and camera-based licence-plate scan recognition.
  • FCA Secure Gateway access with an AutoAuth account. Custom diagnostic reports that you can print and save.
  • MS906Pro-TS exclusive software: complete TPMS functionality and 1-Sensor programming.

For workshops

For workshops that want an 8-inch all-system tablet with 26 service functions and bi-directional controls. Choose MS906Pro-TS if you also need built-in TPMS service and 1-Sensor programming.

MX900

Autel MaxiCheck MX900

8-inch tablet service tool with 40+ maintenance functions.

The MaxiCheck MX900 is an 8-inch tablet service tool for all-system diagnostics and workshop maintenance functions, with AutoVIN, DoIP and CAN FD, plus Pre and Post Scan.

Key features

  • Extensive vehicle coverage for U.S., Asian and European makes, with OE-level system coverage for all electronic systems.
  • Codes, live data, ECU information, active tests and special functions. Smart AutoVIN to identify vehicles easily.
  • DoIP and CAN FD protocols. Supports Pre & Post Scan. Supports all OBD-II protocols and 10 test modes.
  • 40+ maintenance service functions, including diesel particulate filter forced regeneration, steering angle sensor (SAS) reset, oil service and battery registration / BMS, service mileage and interval resets, and opening and closing EPB (electronic brake calipers) for pad replacement.
  • Data Manager for vehicle history, workshop information, customer records, images, reports and data logging.

For workshops

For workshops that want an 8-inch everyday service tablet for all-system diagnostics and common resets — DPF, SAS, oil and battery / BMS, service intervals and electronic parking brake — with Pre and Post Scan.
