EV Upgrade Kit

Autel MaxiSYS EV Diagnostics Upgrade Kit

Add EV battery-pack diagnostics to a compatible MaxiSYS tablet.

This upgrade kit adds EV diagnostics to a compatible MaxiSYS tablet. It includes the EVDiag Box and adapters for specific vehicles, so you can run battery-pack diagnostics on electric vehicles.

Key features

  • Compatible with the MaxiSYS Ultra, MaxiSYS Ultra ADAS, MaxiSYS MS919 and MaxiSYS MS909.
  • Advanced diagnostics for U.S., European and Asian electric, gas and diesel, and hybrid vehicles.
  • In-depth battery-pack diagnostics for popular EVs including BMW, Tesla and Volkswagen/Audi.
  • State of Charge and State of Health analysis for true battery condition.
  • Battery analysis via specialty adapters and jumpers, with detailed connection diagrams for safer testing.
  • The brochure also lists support for Caterpillar, Cummins and Hino engines.

For workshops

For workshops that already have a MaxiSYS Ultra, Ultra ADAS, MS919 or MS909 and want to add EV battery-pack diagnostics, including State of Charge and State of Health analysis.

Hardware & protocols

Kit contents
EVDiag Box and vehicle-specific adapters and jumpers, in a hard case (as shown in the brochure)
Compatible tablets
MaxiSYS Ultra, MaxiSYS Ultra ADAS, MaxiSYS MS919, MaxiSYS MS909

Coverage. Electric, gas, diesel and hybrid vehicles from U.S., European and Asian makers. Battery-pack diagnostics named in the brochure: BMW, Tesla and Volkswagen/Audi. Engine support also listed: Caterpillar, Cummins and Hino.
