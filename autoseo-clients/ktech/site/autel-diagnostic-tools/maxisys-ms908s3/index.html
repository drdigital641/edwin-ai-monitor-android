MS908S3 Kit

Autel MaxiSYS MS908S3 Kit

Advanced diagnostics and information system, with XP400 Pro key programmer included.

The MS908S3 Kit is an advanced diagnostics and information system. The brochure lists a new included XP400 Pro key programmer, together with a MaxiFlash LVCI (SAE J2534, RP1210).

Key features

  • Extensive vehicle coverage for U.S., Asian and European makes, with OE-level system coverage for all electronic systems.
  • Codes, live data, ECU information, bi-directional active tests, special functions, and ECU programming.
  • Supports the latest communication protocols, including DoIP and CAN FD.
  • XP400 Pro supports IMMO functions for BMW, Benz, VW, Audi, Ford, Mazda, Toyota, Honda, Proton and Perodua.

For workshops

For workshops that need a diagnostic tablet plus ECU programming and key programming. The named IMMO list includes Proton and Perodua, which many Malaysian workshops work on.
