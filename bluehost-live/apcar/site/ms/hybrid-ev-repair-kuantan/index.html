Kerja hybrid dan EV

  1. Honda Civic FB Hybrid: tak charging, IMA malfunction, set bateri hybrid + semakan sistem

Bateri hybrid dan aircond kereta hybrid di Kuantan

Kereta hybrid guna bateri voltan tinggi dan selalunya kompresor A/C elektrik, jadi masalah "tak sejuk" boleh jadi masalah hybrid. Kami gabungkan kerja aircond dengan diagnosis hybrid untuk Honda, Toyota dan BMW, dan kami juga terima EV seperti Porsche Taycan dan BMW iX.
