Ask about MBMaster

What MBMaster is

MBMaster is a professional tool for workshops and locksmiths that work on Mercedes-Benz vehicles. The screenshots on this page are from MBMaster V1.5. Identifying details in every screenshot are blurred.

What the app shows

Main function tabs in V1.5:

  • Identify
  • Software Read
  • EIS Boot/Simu
  • Single MCU Read/Write
  • Nec/OC
  • Coding
  • Advanced Services
  • Special Functions
  • Program

Sub-tabs visible in the app:

  • Cluster
  • NCV2 / ISM
  • Gearbox VGS
  • Gearbox VDK

The demo: a used gearbox module, reset for repair

The demo uses a VGS4 NAG2 7-speed gearbox module. MBMaster reads the module’s info and its anti-theft data.

The app’s Clear (Unlock) Restore Anti Theft function resets a used or replacement module to a virgin state, so it can be fitted in an authorised repair. Before it starts, a confirm dialog says the module must be a replacement module, not the original car, and that the process flashes it to virgin state and clears its anti-theft data.

After the process, the console reports that verification passed and the anti-theft data was erased.

Other functions seen in the app

  • Read Module Info
  • Read Anti Theft Data
  • Erase used module
  • Write Original Data
  • One Click Restore Anti Theft
  • Write Coding
  • Write Original Anti Theft to Used Module

Button names are shown as they appear in the app.
