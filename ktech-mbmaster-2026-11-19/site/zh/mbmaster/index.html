MBMaster 是什么

MBMaster 是为维修 MB 车辆的车厂与锁匠而设的专业工具。本页截图来自 MBMaster V1.5。所有截图中的识别信息均已模糊处理。

软件界面显示的内容

V1.5 的主要功能分页：

  • Identify
  • Software Read
  • EIS Boot/Simu
  • Single MCU Read/Write
  • Nec/OC
  • Coding
  • Advanced Services
  • Special Functions
  • Program

软件中可见的子分页：

  • Cluster
  • NCV2 / ISM
  • Gearbox VGS
  • Gearbox VDK

演示：二手变速箱模块，重置后用于维修

演示使用的是一个 VGS4 NAG2 7 速变速箱模块。MBMaster 读取该模块的信息及其防盗数据。

软件中的 Clear (Unlock) Restore Anti Theft 功能可将二手或替换模块重置为空白（virgin）状态，以便在获授权的维修中装用。开始前，确认对话框会提示：模块必须是替换模块，不能是原车模块；此过程会将模块刷写为空白状态并清除其防盗数据。

完成后，控制台显示验证通过，防盗数据已清除。

软件中可见的其他功能

  • Read Module Info
  • Read Anti Theft Data
  • Erase used module
  • Write Original Data
  • One Click Restore Anti Theft
  • Write Coding
  • Write Original Anti Theft to Used Module

按钮名称与软件中显示的一致。

仅限获授权的维修工作

K Tech 向专业车厂与锁匠提供 MBMaster，用于经车主授权的维修及替换模块工作。
