MBMaster V1.5 untuk kenderaan MB

Alat profesional untuk bengkel dan tukang kunci, kini di K Tech.

Tanya tentang MBMaster

Apa itu MBMaster

MBMaster ialah alat profesional untuk bengkel dan tukang kunci yang membaiki kenderaan MB. Tangkapan skrin di halaman ini adalah daripada MBMaster V1.5. Butiran pengenalan dalam setiap tangkapan skrin telah dikaburkan.

Apa yang ditunjukkan aplikasi

Tab fungsi utama dalam V1.5:

  • Identify
  • Software Read
  • EIS Boot/Simu
  • Single MCU Read/Write
  • Nec/OC
  • Coding
  • Advanced Services
  • Special Functions
  • Program

Sub-tab yang kelihatan dalam aplikasi:

  • Cluster
  • NCV2 / ISM
  • Gearbox VGS
  • Gearbox VDK

Demo: modul gearbox terpakai, ditetapkan semula untuk pembaikan

Demo ini menggunakan modul gearbox VGS4 NAG2 7 kelajuan. MBMaster membaca maklumat modul dan data anti-kecuriannya.

Fungsi Clear (Unlock) Restore Anti Theft dalam aplikasi menetapkan semula modul terpakai atau modul ganti kepada keadaan dara (virgin), supaya ia boleh dipasang dalam pembaikan yang dibenarkan. Sebelum bermula, dialog pengesahan menyatakan modul mestilah modul ganti, bukan dari kereta asal, dan proses ini memprogram (flash) modul ke keadaan dara serta mengosongkan data anti-kecuriannya.

Selepas proses, konsol melaporkan pengesahan lulus dan data anti-kecurian telah dipadam.

Fungsi lain yang kelihatan dalam aplikasi

  • Read Module Info
  • Read Anti Theft Data
  • Erase used module
  • Write Original Data
  • One Click Restore Anti Theft
  • Write Coding
  • Write Original Anti Theft to Used Module

Nama butang ditunjukkan seperti dalam aplikasi.
