Demo tour

Twelve things to try in this mockup. Everything you add or send stays in this browser; nothing reaches customers or the live website.

  1. 1. Search a part number

    Type 8730R. The BMW 2 Series F45/F46 compressor comes up as an exact reference match, with R1234YF and PAG-46.

    Try it
  2. 2. Search like a buyer

    Type “BMW F45 compressor”: the same part, found by vehicle and part type.

    Try it
  3. 3. Spaces and dashes don't matter

    4M0816421B finds the Audi Q7 condenser listed as 4M0 816 421B, with a fitment check note.

    Try it
  4. 4. Chassis code search

    Mercedes W205 compressor finds the Sanden Europe compressor, reference 1787.

    Try it
  5. 5. No made-up results

    Mercedes W210 compressor is not in the catalogue, so the search says so and offers “Request sourcing”.
