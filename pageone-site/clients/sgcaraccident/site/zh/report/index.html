保险公司报案警方报案要带什么陈述帮手

1. 向您的保险公司报案

须在24小时内或下一个工作日之前向保险公司报案。无论车辆是否受损，都要把车开到保险公司认可的报案中心或授权车厂。（GIA汽车索赔框架）

在报案中心，工作人员会协助您完成并提交最终的事故报告。

2. 警方报案：只在这些情况下需要

事故涉及以下任何一项时，需要向交通警察报案：

  • 有人死亡
  • 有人被救护车送院，或获得3天或以上的病假
  • 政府财产受损
  • 涉及外国车辆
  • 涉及行人或骑脚车者
  • 肇事逃逸

可通过新加坡警察部队（SPF）电子服务的交通事故报告在线报案（需要Singpass），或到任何警署报案。向警方报案不能代替向保险公司报案。

向保险公司报案和向交通警察报案是两回事。警方报告不能取代向保险公司报案。

3. 要带什么

  • 您的车辆，无论有没有损坏，只要能行驶
  • 您的身份证和驾照
  • 您的保险证明
  • 对方司机的姓名、身份证号码、电话号码、地址、保险公司和车牌号码
  • 现场和所有车辆的照片
  • 行车记录仪录像
  • 警方报告（如果有）

各保险公司要求的文件略有不同。如果还需要其他文件，您的报案中心会告诉您。

4. 准备您的事故陈述

请填写您所知道的内容。它会变成一份清楚的陈述，报案时您可以复制、打印或存在手机里。

大家常问的问题
没有损坏也要报案吗？
要。GIA 表示，所有驾驶者都必须向保险公司报告任何事故，无论多小，并把车辆（无论有没有损坏）开到报案中心。
在这里做陈述就等于提交了报案吗？
不是。它只是帮您准备。您仍然需要到报案中心向保险公司报案，如果您的情况需要，也要向警方报案。
如果我延迟报案怎么办？
请尽快报案。GIA 表示，如果延迟有正当理由，您不会受到处罚；否则延迟报案或不报案，可能影响您的索赔和 NCD。
